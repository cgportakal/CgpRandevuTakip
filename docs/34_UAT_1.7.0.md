## 3. Manuel kontrol listesi

### 3.1 Raporlar
- [ ] Rapor türü seçicisiyle 7 tür açılır.
- [ ] Excel çıktısında türe özel sayfalar oluşur.
- [ ] Kişi geçmişinde ad/telefon araması doğru sonuç verir.
- [ ] Denetim raporu yalnızca denetim kayıtlarını listeler.
- [ ] 2.000+ satırlık aralıkta sayfa makul sürede yüklenir.

### 3.2 Seri yönetimi
- [ ] Seriye 1–12 kayıt eklenir; toplam sayı ve sıra numaraları güncellenir.
- [ ] Aylık seride çapa günü korunur (31 → ay sonu → 31).
- [ ] Düzenleme yalnızca gelecek planlanmış kayıtları değiştirir.
- [ ] Saat değişiminde çakışan kayıtlar atlanır ve uyarı gösterilir.
- [ ] Geçmiş/kapalı kayıtlar değişmez.

### 3.3 Mobil
- [ ] API çalışırken giriş ve gün listesi yüklenir.
- [ ] Çevrimdışıyken yeni görüşme kuyruğa alınır; bağlantı gelince gönderilir.
- [ ] Sonuç girişi ve seri iptali çevrimdışı kuyrukta çalışır.
- [ ] Rapor ekranı özet ve görüşmeci performansını gösterir.

### 3.4 API
- [ ] `GET /v1/reports/{kind}` görüşmeci rolünde yalnızca kendi verisini döndürür.
- [ ] Seri uçları yetkisiz kullanıcıda 403/401 döndürür.

### 3.5 UI otomasyonu
- [ ] `CGP_UI_TESTS=1` ile FlaUI testleri yayınlanmış EXE üzerinde çalışır.
- [ ] Testler kendi geçici verisini oluşturur ve siler.
