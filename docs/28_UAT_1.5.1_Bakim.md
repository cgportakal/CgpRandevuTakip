# 28 — 1.5.1 Bakım UAT: Başlangıç Onarımı ve Temiz Kaldırma

**Tarih:** 16.11.2026 · **Sürüm:** 1.5.1

## 1. Kapsam

- Windows açılışında çıkan **Windows Script Host** hatasının giderilmesi.
- Ölü başlangıç girdilerinin ve bildirim kayıtlarının temizlenmesi.
- Kaldırmanın tüm artıkları temizlemesi; veri ve yedek davranışı.
- 1.5.0 → 1.5.1 yerinde yükseltme.
- Taşınabilir paket politikası.

## 2. Otomatik testler

| Alan | Sonuç |
|---|---|
| Uygulama testleri | **280/280** |
| Desktop testleri | **26/26** |
| Toplam | **306/306** |
| Release derleme | 0 uyarı / 0 hata |

Yeni Desktop testleri: VBS sessiz-hata koruması, `--tray`, portable/kurulu mod yazımı, ölü hedef onarımı, boş `Run` temizliği, komut satırından yol ayrıştırma.

## 3. Başlangıç hatası (gerçek makine)

| Adım | Sonuç |
|---|---|
| Silinmiş test kopyasına işaret eden `Startup\CGP - Randevu Takip.vbs` | Silindi |
| Boş `HKCU\...\Run\CgpRandevuTakip` değeri | Silindi |
| Birikmiş bildirim kayıtları | 15 AUMID + 18 CLSID + 20 ikon klasörü temizlendi |
| Kurulu sürüm için doğru `Run` değeri | `"...\CgpRandevuTakip.Desktop.exe" --tray` |

**Onarım testi:** Ölü hedefe işaret eden VBS ve boş `Run` değeri yeniden oluşturuldu; uygulama `--tray` ile açıldığında VBS silindi ve `Run` değeri geçerli yolla yenilendi.

## 4. Yükseltme (1.5.0 → 1.5.1)

| Kontrol | Sonuç |
|---|---|
| Yerinde yükseltme | Başarılı (`FileVersion 1.5.1.0`) |
| Kaldırma kaydı | Tek kayıt, tek `unins000.exe` |
| Kullanıcı verisi | Korundu (`data.db` yerinde) |
| Başlangıç kaydı | Doğru EXE yoluna güncellendi |

> Not: Installer `AppId` değerindeki kaçış (`{{...}}`) düzeltildi; yükseltmeler aynı kaldırma kaydını kullanır.

## 5. Kaldırma

### 5.1 Veri koruma (varsayılan / sessiz)

| Kontrol | Sonuç |
|---|---|
| Program klasörü | Silindi |
| Başlat menüsü / masaüstü kısayolu | Silindi |
| `Uninstall` kaydı | Silindi |
| `Run` değeri, Startup VBS/LNK | Silindi |
| Bildirim kayıtları (AUMID/CLSID/ikon) | Silindi |
| `updates` anlık görüntüsü | Silindi |
| Kullanıcı verisi (`%LOCALAPPDATA%\CgpRandevuTakip`) | **Korundu** |
| Yedekler (`Belgeler\CgpRandevuTakip`) | **Korundu** |

### 5.2 Veri silme onayı

- Etkileşimli kaldırmada “Uygulama verileri de silinsin mi?” sorusu gösterildi.
- **Evet** seçildiğinde: veritabanı, ayarlar ve günlükler silindi; **yedekler korundu**.
- “Hayır” seçildiğinde veya sessiz kaldırmada veriler korunur.

## 6. Taşınabilir politika

- `Kurulum-Olustur.ps1` varsayılan olarak **ZIP üretmez**; yalnızca `-Portable` ile üretir.
- 1.5.1 yalnızca Setup EXE olarak yayınlandı; son taşınabilir paket 1.5.0’dır.
- Taşınabilir başlatıcı hedef yoksa sessiz çıkar; kopya taşınsa/silinse hata penceresi çıkmaz.

## 7. Bilinen sınırlar

- Üretim dijital imzası (CA/PFX) temin edilene kadar Setup “Bilinmeyen yayıncı” gösterebilir.
- Kaldırma onayı `MsgBox` ile gösterilir; tam otomatik (sessiz) kaldırmada veri korunur.
